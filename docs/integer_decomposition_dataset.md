# 整数分解：两档固定测试题包

题目来源：[苏剑林，2023-09-20，自然数集中 N = ab + c 时 a + b + c 的最小值](https://spaces.ac.cn/archives/9775)。
本站备用域名：[kexue.fm](https://kexue.fm/archives/9775)。
原文以“尽量小”的问题出发；本项目采用其最小值目标，补充明确输入输出、数据范围和资源限制，形成两个精确求解版本。
时限与测试数据由本项目设计，不是博客原有的 OJ 数据。

| 版本 | N 范围 | 单测试时限 | 容器内存 | 公开 / 私有测试 | 预期复杂度 |
|---|---|---|---|---|---|
| 基础版 | 101～10^12 | 1 秒 | 256 MB | 4 / 71 | O(sqrt(N)) |
| 大数据版 v2 | 101～2^63−1 | 1 秒 | 256 MB | 4 / 86 | O(N^(1/4)) |

每个输入文件只有一个 N。输出三个非负十进制整数 a b c，满足 N=ab+c 且和值最小。
特殊校验器接受全部最优三元组，包括交换 a、b 的写法；不比较三元组的字面顺序。

## 正确性与数据设计

平方根参考实现完整枚举 1≤a≤floor(sqrt(N))，固定 a 后取 b=floor(N/a)。对 a≥1，和值随 b 增大不增；对称性保证覆盖最优解。
原文的初步缩区间为开区间 `(sqrt(N/2), sqrt(N)]`，直接实现会在 N=128 漏掉 (8,16,0)，因此不作为精确标答来源。基础版保留同阶复杂度的完整枚举。

四次根实现采用原文的 p=a+b、q=b−a 参数化，选择满足平方差条件和同奇偶约束的最小 q。
实现使用整数平方根，并以已有可行解的和值收缩 p 的上界：p 不小于当前和值后不可能改进。
因此避免浮点开根与固定窗口近似。生成器还用独立的同/异奇偶 x,y 参数化检查大整数结果。

测试覆盖：

- N=101 起的小数值、N=128 的区间边界、N=130 的“只试最接近平方数”反例。
- 完全平方数及前后 1、2；相邻整数乘积及前后 1；奇偶分支。
- 两档上界附近和固定种子的随机大数。
- 超过 2^53 的整数，检查浮点精度和整数溢出问题。
- 两个参考算法在 101～20000 全量对比，全部固定点另经独立奇偶参数化交叉核验。

## 判题边界

两版统一使用每测试 1 秒、256 MB、1 vCPU，通过 N 的规模区分算法强度。
校准要求：基础版 Python/C++ 平方根参考解均为 75/75 AC，大数据版 Python/C++ 四次根参考解均为 90/90 AC。
实测耗时记录于 `benchmark.json`。
完整平方根枚举（Python/C++）以及原文缩区间枚举（C++），在三条 64 位大数压力点上均为 TLE。

已注册 checker 的判定具有权威性：拒绝非最优、非法三元组和额外输出；checker 加载或执行失败不会默认 AC。
Python3 和 C++17 都运行相同 checker。判题结果独立于过程审查；过程审查仍检查题解和解题轨迹。
旧版 AI 测例历史不改写为固定测试结果，录制应使用新题包重新提交或明确标注相应复验记录。
